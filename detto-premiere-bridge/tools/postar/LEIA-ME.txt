POSTAGEM AUTOMÁTICA — Instagram @detto.galo + TikTok @detto.galo e @detto.tv
(configuração UMA VEZ SÓ; depois o PC posta sozinho)
O jeito fácil de usar tudo isto é o PAINEL: tools\painel\LEIA-ME.txt (chaves, logins, fila e horários pelo navegador).

=====================================================================
 1) INSTAGRAM @detto.galo  (posta de verdade, com legenda; por padrão como REELS TESTE)
=====================================================================
Antes: o @detto.galo precisa ser conta PROFISSIONAL (Criador ou Empresa) e estar LIGADO a uma Página do
Facebook (Instagram → Configurações → Central de contas, ou na Página: Configurações → Contas vinculadas).

 a) developers.facebook.com → Meus apps → Criar app → tipo "Empresa" (Business).
 b) No app, adicione os produtos "Instagram" (API com login do Facebook) e "Login do Facebook para Empresas".
 c) Configurações do app → Básico: copie o "ID do app" e a "Chave secreta do app".
 d) Rode uma vez (cria a pasta E:\DETTO\postar e o config.json):
       python tools\postar\postar.py --status
    Abra E:\DETTO\postar\config.json e preencha em "instagram": "app_id" e "app_secret".
 e) Login:
       python tools\postar\postar.py --login instagram --conta detto.galo
    Abre o navegador → entre no Facebook dono da Página → marque a Página e o @detto.galo → Permitir.
    (O endereço http://localhost:8724/ já é aceito com o app em modo "Desenvolvimento". Se reclamar,
     ponha esse endereço em "URIs de redirecionamento do OAuth válidos" no Login do Facebook.)
 PLANO B (se o login pelo navegador der erro):
    developers.facebook.com/tools/explorer → escolha o app → "Gerar token de acesso" com as permissões
    instagram_basic, instagram_content_publish, instagram_manage_insights, pages_show_list, pages_read_engagement, business_management
    → copie o token e rode:
       python tools\postar\postar.py --login instagram --conta detto.galo --token COLE_AQUI
 O sistema troca por um token de longa duração (o da Página não vence). Não precisa publicar/revisar o app
 enquanto só VOCÊ usa (você é o administrador).

=====================================================================
 2) TIKTOK @detto.galo e @detto.tv  (vai como RASCUNHO até o app ser aprovado)
=====================================================================
 a) developers.tiktok.com → login → Manage apps → Connect an app (tipo "Desktop" / uso próprio).
 b) Adicione os produtos "Login Kit" e "Content Posting API". Escopos: user.info.basic e video.upload.
 c) Login Kit → Redirect URI (Desktop):  http://localhost:8723/callback/
 d) Aba "Sandbox": crie o sandbox e adicione @detto.galo e @detto.tv como "Target users".
 e) Copie "Client key" e "Client secret" (do sandbox) para "tiktok" no config.json.
 f) Login de cada conta (no navegador, entre na conta certa antes de autorizar):
       python tools\postar\postar.py --login tiktok --conta detto.galo
       python tools\postar\postar.py --login tiktok --conta detto.tv
 Como funciona no modo RASCUNHO:
    - o vídeo cai na caixa de entrada do TikTok da conta (chega notificação no celular);
    - abra, cole a legenda do arquivo  E:\DETTO\postar\legendas_tiktok_<conta>.txt  e toque em Publicar;
    - o TikTok aceita no máximo 5 rascunhos esperando por conta: o sistema só manda o próximo quando
      você publicar (ou apagar) um. Veja quantos estão esperando com --status.
 Postar 100% sozinho no TikTok: peça a aprovação ("Submit for review") do app com o escopo video.publish.
 Aprovado → no config.json, "tiktok": {"modo": "direto"} (e "ia": true se o vídeo for gerado por IA).
 Sem aprovação o TikTok só deixa a API postar como PRIVADO, por isso o padrão é rascunho.

=====================================================================
 3) LIGAR SOZINHO
=====================================================================
 Com o painel instalado (python tools\painel\painel.py --instalar) ele mesmo posta. Sem o painel:
       python tools\postar\postar.py --agendar
 O Windows roda a cada 20 min (com o PC ligado e você logado). Cada conta respeita o seu intervalo,
 horário e máximo por dia (config.json → "contas": intervalo_min, horas "08-23", max_dia, ativo).

=====================================================================
 USO NO DIA A DIA
=====================================================================
 - Reels automáticos (tools\reels\reels.py): já entram na fila do Instagram e do TikTok do @detto.galo.
   Para não entrar: no config.json dos reels, "postar": [].
 - @detto.tv: jogue o .mp4 em  E:\DETTO\postar\entrada\tiktok_detto.tv\  (se quiser, um .txt com o
   MESMO NOME com a legenda + tags). Sai na ordem do nome do arquivo (ou a que você arrumar no painel).
 - Qualquer vídeo em qualquer conta: jogue na pasta  entrada\<plataforma>_<conta>\ .
   Texto depois de uma linha "---" no .txt NÃO vai para a legenda (anotações).
 - Ver a situação:    python tools\postar\postar.py --status
 - Postar já um vídeo: python tools\postar\postar.py --agora "video.mp4" --para instagram:detto.galo
 - Postados vão para postados\<conta>\ (com o link no .json); erro 3 vezes seguidas → falhas\<conta>\.
 - Vídeo para o Instagram: MP4 (H.264/AAC), 9:16, até 15 min — os reels do sistema já saem assim.
